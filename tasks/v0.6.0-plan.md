# Implementation plan: v0.6.0 configurable homepage

## Task list

### Slice 1: Homepage configuration contract

1. Extend the immutable configuration model and parser with optional homepage
   cards and section switches.
2. Render the configured cards and only the enabled homepage sections.
3. Verify with configuration and build tests.

### Slice 2: Author-facing documentation

4. Document the configuration contract and add three copyable recipes.
5. Add the recipes to the project documentation navigation.
6. Verify with the documentation checker and a built site.

### Slice 3: Release gate

7. Update version, changelog, roadmap, and immutable version manifest.
8. Run the full test suite, release validation, and historical build.
9. Review the change across correctness, readability, architecture, security,
   performance, and browser accessibility before opening the PR.

## Risks and mitigations

| Risk | Mitigation |
| --- | --- |
| A new option changes old sites | Defaults exactly mirror v0.5.0 output and have regression tests. |
| Card content is unsafe | Validate strings and escape all rendered text. |
| Section visibility makes page structure unclear | Restrict the four known homepage sections and document their defaults. |
