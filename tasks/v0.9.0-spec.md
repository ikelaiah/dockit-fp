# Spec: v0.9.0 dependable publishing

## Objective

Make single-version and historical GitHub Pages publication inspectable,
deterministic and difficult to misconfigure, with actionable diagnostics and
release-ready examples.

## Scope

- Make `doctor` report Git, immutable-ref and Pages-workflow readiness for
  common repository states.
- Harden release manifests against unsafe release paths/refs and ensure the
  current immutable source matches the checked-out release.
- Support both historical and single-version sites in the reusable Pages
  workflow while preserving versioned publication as the default.
- Upgrade official Pages actions to their current Node.js 24 majors.
- Publish maintained single-version and historical examples, deterministic
  historical-build coverage, a pre-publish checklist and direct upgrade
  guidance from every supported 0.x release.

## Commands

- Focused: `python -m unittest tests.test_cli tests.test_versions tests.test_workflows -v`
- Full suite: `python -m unittest discover -s tests -t . -v`
- Documentation: `$env:PYTHONPATH='src'; python -m dockit_fp check --root .`
- Release: `$env:PYTHONPATH='src'; python -m dockit_fp check-release --root .`
- Historical build: `$env:PYTHONPATH='src'; python -m dockit_fp build-all --root . --output build/docs-site`

## Boundaries

- Preserve existing versioned workflow callers through default input values.
- Keep workflow input interpolation out of shell source.
- Use only immutable tags or full commit SHAs for historical sources.
- Keep examples dependency-free and all generated assets local.

## Success criteria

- Common missing-Git, missing-tag, mismatched-current-ref and Pages states have
  one actionable diagnosis.
- Unsafe release paths and Git-like option refs are rejected before Git or file
  operations.
- Both maintained examples build, and the historical fixture is byte-for-byte
  deterministic across repeated builds.
- GitHub Pages runs without deprecated Node.js action warnings.
- A maintainer can follow one checklist and upgrade directly from any supported
  0.x release.
