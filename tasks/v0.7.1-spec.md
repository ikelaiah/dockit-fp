# Spec: v0.7.1 historical-build compatibility

## Objective

Restore release-tag documentation builds for v0.7.0 without changing any
published tag.

## Scope

- Keep strict unlisted-Markdown validation for the manifest's current release.
- Render historical tags using the rules available when those tags were
  authored.
- Cover a modern historical release with an unlisted Markdown document.

## Verification

- `python -m unittest tests.test_versions -v`
- `python -m unittest discover -s tests -t . -v`
- `$env:PYTHONPATH='src'; python -m dockit_fp check --root .`

## Boundaries

- Do not move or replace the published `v0.7.0` tag.
- Do not relax validation for the current documentation release.
