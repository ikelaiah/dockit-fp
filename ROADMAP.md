# Roadmap

## v0.1.x

Shared CLI, modern and legacy sites, historical builds, semantic themes,
search, responsive layout, validation, fixtures and reusable Pages publishing.

## v0.2.x

Harden migration based on the first real downstream project and refine release
workflow ergonomics.

## v0.3.x

Expand PasWeave integration examples, accessibility checks and release tooling.

## Pre-1.0 and v1.0

Migrate projects one at a time and stabilise the CLI, schemas, theme-token
contract, Pages integration, historical behaviour and migration pattern.
