# Spec: v0.7.2 Classic System dark mode

## Objective

Make Classic documentation pages follow the browser's dark system preference
when a visitor selects System colour mode.

## Scope

- Apply the existing dark semantic tokens through `prefers-color-scheme`.
- Limit the rule to Classic with no explicit Light or Dark selection.
- Preserve Paper and Midnight visual themes.

## Verification

- `python -m unittest tests.test_build.BuildSiteTests.test_builds_modern_navigation_search_and_theme_tokens -v`
- `python -m unittest discover -s tests -t . -v`
- `$env:PYTHONPATH='src'; python -m dockit_fp check --root .`
