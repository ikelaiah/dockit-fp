# Implementation plan: v0.7.0 authoring and navigation

### Slice 1: Safe authoring and navigation validation

1. Add definition-list rendering with regression tests.
2. Validate that every modern Markdown document is listed in navigation, and
   include the configuration's section count in build results.
3. Report the section/page summary from `dockit-fp check`.

### Slice 2: Local search experience

4. Rank local results deterministically by title, section, then document text.
5. Improve previews and provide keyboard guidance and Home/End result movement.
6. Verify generated markup and scripts without adding a client dependency.

### Slice 3: Documentation and release

7. Add authoring recipes and list all project documentation in navigation.
8. Update version, changelog, roadmap, migration guidance, and manifest.
9. Run automated, documentation, immutable-release, and review gates before
   opening the release PR.
