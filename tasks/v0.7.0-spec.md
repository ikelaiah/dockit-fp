# Spec: v0.7.0 authoring and navigation

## Objective

Make common Free Pascal documentation easier to author, navigate, and search
without adding dependencies or remote assets.

## Scope

- Render Markdown definition lists (`Term` followed by `: Description`) as
  escaped semantic HTML for unit, type, and option reference prose.
- Require every modern documentation Markdown file to be listed in
  `layout.json`, retaining the existing missing-navigation-page check and
  reporting the exact unlisted path.
- Make `dockit-fp check` report section and page totals.
- Rank local search matches by title, section, and document text; keep compact
  query-centred previews and improve keyboard guidance and Home/End movement.
- Publish authoring recipes for library, application, and reference structures.

## Commands

- Focused: `python -m unittest tests.test_markdown tests.test_config tests.test_cli tests.test_build -v`
- Full suite: `python -m unittest discover -s tests -t . -v`
- Documentation check: `$env:PYTHONPATH='src'; python -m dockit_fp check --root .`

## Boundaries

- Always: preserve safe escaping, local-only assets, current Markdown output,
  and keyboard access.
- Ask first: add dependencies, change the JSON schema version, or alter CI.
- Never: silently omit modern Markdown content from navigation or rely on a
  hosted search service.

## Success criteria

- Definition lists render predictably and safely.
- `check` identifies unlisted modern Markdown files and reports a navigation
  summary.
- Search ranks useful results first, gives a readable preview, and can be
  driven with the documented keyboard controls.
- Copyable structure recipes pass the documentation checker.
